📚 Documentation

Getting Started

  • • Install dependencies: pip install -r requirements.txt
  • • Run backend: python app.py
  • • Open this dashboard in browser
  • • Start adding messages and creating checkpoints

Key Concepts

  • • Working Memory: Active context (RAM)
  • • Paged Memory: Evicted context (Disk)
  • • Checkpoints: State snapshots
  • • Steps: Transactional operations

API Base URL

http://127.0.0.1:8000/api

Configuration

  • • Max Working Memory: 5 items
  • • Auto-paging: Enabled
  • • CORS: Enabled

Available Endpoints

GET /api/state

Fetch current engine state

POST /api/message

Add message to working memory

POST /api/checkpoint

Create a state checkpoint

POST /api/rollback

Restore from checkpoint

POST /api/step

Execute a transactional step

GET /api/history

View execution history

⚠️ Reset State Engine?

This will clear:

  • ✓ All working memory messages
  • ✓ All paged memory messages
  • ✓ All checkpoints
  • ✓ All step history
